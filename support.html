Feed Filter support

This project is an early preview. The Chrome Web Store listing is not published yet.

Before reporting a problem

  • Check the version at the bottom of the popup.
  • For a manually installed copy, reload the extension on chrome://extensions and refresh YouTube.
  • Confirm filtering is enabled and the relevant category or topic is selected.
  • Category/tag checks can fail because of missing metadata, consent pages, network failures or rate limits. Title/channel matching still works.

Report a bug or ask a privacy question

Use the public support tracker. Include the extension version, Chrome version, whether the issue is on Home or a watch page, and a short description. A public video link is helpful if you are comfortable sharing it.

Issues are public. Do not include API keys, account details, private browsing history or screenshots containing personal information. For sensitive matters, begin by asking the maintainer for an appropriate contact method without posting the sensitive details.

Resetting your data

Remove topics or change categories in the popup. Refresh or close YouTube to clear tab-memory metadata. Uninstalling removes the extension's stored settings.
